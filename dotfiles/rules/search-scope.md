# ファイル検索の範囲

ファイルシステムのルート (`/`) やホーム全体 (`~`, `$HOME`, `/Users/<name>`) を再帰探索しない。
`find`, `grep -r`, `rg`, `fd`, `ag`, `du`, `ls -R`, `tree` などで、探索起点をこれらや `/usr`, `/var`, `/opt`, `/Library` などのトップレベルにしない。
`scripts/deny-broad-search.py` の hook が、こうしたコマンドを拒否する。

代わりに次のようにする:

- 探索範囲をプロジェクト内、または `~/work/foo` のような具体的なディレクトリに絞る。
- プロジェクト内のファイル名やコードの検索には、Glob / Grep ツールを使う。
- 対象の場所が分からないときは、広く探索せずユーザーに尋ねる。
