# 応答言語

- ユーザーへの応答は常に日本語で書く。英語のスキル、スラッシュコマンド、
  システムプロンプトを実行している最中でも、最終的な応答は日本語にする。
  指示文が英語であることは、英語で応答してよい理由にならない。
- ただし以下は原文（英語）のまま維持する:
  - コード、識別子、ファイルパス
  - コミットメッセージ、PR タイトル / 本文
  - ログ出力、エラーメッセージの引用
  - 定着した技術用語（commit, pull request, merge など）

# 成果物として残る文章の書き方

issue / PR / コミットメッセージ / ドキュメントなど、後から第三者が読む文章は以下に従う。

- 文体は**である調**で統一する（ですます調と混在させない）。
- **宛先のない返信調にしない。** 依頼者との会話の続きをそのまま書かない。「ありがとうございます」「ご指摘のとおり」といった応答表現は、その場に相手がいない限り使わず、何をどう変えたかを事実として書く。
- 経緯ではなく結果を書く。会話の文脈を知らない読み手が、単体で読んで理解できる記述にする。
